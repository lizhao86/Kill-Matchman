# Kill Matchman

一款纯前端 Canvas 网页小游戏。玩家可以在草地场景里选择不同武器攻击火柴人，也可以放置食物、家具，或手动生成指定类型的火柴人。火柴人有自己的 AI，会逃跑、回血、休息、追击、攻击，僵尸还能把其他火柴人感染成僵尸。

在线试玩：https://kill-matchman.vercel.app

## 快速开始

本项目没有构建步骤，也不需要安装 npm 依赖。由于源码使用 ES Modules，请通过本地 HTTP 服务打开，不能直接双击 `index.html`。

```bash
cd sourcecode
python -m http.server 8080
```

然后在浏览器打开：

```text
http://localhost:8080
```

如果你的系统里 `python` 指向 Python 2，可以改用：

```bash
python3 -m http.server 8080
```

## 玩法

1. 在底部工具栏选择 `武器`、`物品` 或 `生成` 标签。
2. 在 `武器` 标签里点选武器，按住鼠标或手指划过火柴人即可连续攻击。
3. 在 `物品` 标签里点选食物或家具，再点击草地区域放置。
4. 在 `生成` 标签里点选火柴人类型，再点击草地区域生成。
5. 右键或按 `Esc` 可以取消当前装备/放置状态。
6. 点击 `RESET` 可以重置本局。

## 游戏系统

### 火柴人类型

| 类型 | 生命值 | 速度 | 闪避 | 行为特点 |
| --- | ---: | ---: | ---: | --- |
| 普通 | 100 | 60 | 40% | 会吃食物、会休息，遇到僵尸会逃跑 |
| 僵尸 | 80 | 35 | 10% | 不吃食物、不休息，会追击非僵尸目标并造成感染 |
| 装甲 | 200 | 45 | 20% | 承受伤害减半，会追击僵尸 |
| 军人 | 150 | 80 | 70% | 移动快、闪避高，会追击僵尸 |

低血量时，普通、装甲和军人的闪避概率会进一步提高。

### 武器

| 武器 | 基础伤害 | 特点 |
| --- | ---: | --- |
| 小刀 | 10 | 轻量近战攻击 |
| 菜刀 | 15 | 中等近战攻击 |
| 大剑 | 25 | 击退更强，并触发屏幕震动 |
| 鞭子 | 12 | 击退距离较远 |
| 毒水 | 持续伤害 | 可叠加中毒层数，每层提高后续毒伤并降低移动速度 |
| 炸弹 | 40 | 爆炸粒子和强屏幕震动 |

武器命中后会出现火花、血滴、伤害数字等粒子效果。火柴人死亡后会倒地，随后灵魂上升并在短暂延迟后刷新新的随机火柴人。

### 物品

| 物品 | 类型 | 效果 |
| --- | --- | --- |
| 面包 | 食物 | 恢复 20 HP |
| 苹果 | 食物 | 恢复 10 HP |
| 水 | 食物 | 恢复 15 HP |
| 果汁 | 食物 | 恢复 25 HP |
| 椅子 | 家具 | 休息 3 秒，获得 8 秒 30% 移速加成 |
| 沙发 | 家具 | 休息 4 秒，获得 10 秒 50% 移速加成 |
| 床 | 家具 | 休息 5 秒，获得 12 秒 80% 移速加成 |
| 桌子 | 障碍物 | 不提供休息加成，会阻挡火柴人移动 |

食物被吃掉后会消失；家具会保留在场地中。

### AI 行为

- 火柴人会在场地底部草地区域随机移动。
- 受伤后，能进食的火柴人会主动寻找最近的食物回血。
- 有家具且当前没有加速效果时，火柴人可能会去家具处休息，休息结束获得移速加成。
- 普通火柴人会躲避附近僵尸。
- 僵尸会追击非僵尸目标；被僵尸击杀的目标会进入感染动画，随后变成僵尸。
- 装甲和军人会主动追击僵尸。

## 技术说明

- 渲染：Canvas 2D 负责游戏画面、火柴人、场景和粒子；DOM 负责顶部计数器和底部工具栏。
- 语言：原生 HTML/CSS/JavaScript，JS 使用 ES Modules。
- 依赖：无运行时依赖、无构建工具。
- 字体：页面引用 Google Fonts。
- 部署：静态站点，可直接部署 `sourcecode/` 目录。
- 适配：支持桌面鼠标操作和移动端触控操作。

## 部署

Vercel 静态部署时，将项目根目录指向 `sourcecode/`，或在 Vercel 项目里配置输出目录为 `sourcecode`。

当前线上地址：

```text
https://kill-matchman.vercel.app
```
