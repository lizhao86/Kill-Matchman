# Kill Matchman

> 解压类网页游戏：用各种武器攻击屏幕上的火柴人，同时火柴人会利用场地上的食物和家具自救。

**在线试玩**: https://kill-matchman.vercel.app

游戏设计草图见 `01 Game Plan/IMG_6565.jpg`

## 玩法

1. **选择武器** — 底部工具栏点击武器装备（小刀/菜刀/大剑/鞭子/毒水/炸弹）
2. **攻击火柴人** — 按住鼠标在火柴人身上划过即可连续攻击
3. **布置场地** — 切换到"物品"标签，点击地面放置食物或家具
4. **火柴人会自救** — 低血时寻找食物补血，空闲时坐家具休息获得加速
5. **击杀与重生** — 火柴人死亡后灵魂升天，2 秒后重生新的随机类型火柴人

## 火柴人类型

| 类型 | 血量 | 速度 | 闪避 | 特殊 |
|------|------|------|------|------|
| 普通 (黑色) | 100 | 正常 | 40% | 无 |
| 僵尸 (绿色) | 80 | 慢 | 10% | 不吃食物、不休息 |
| 装甲 (头盔) | 200 | 慢 | 20% | 伤害减半 |
| 军人 (贝雷帽) | 150 | 快 | 70% | 极高闪避 |

## 武器

| 武器 | 伤害 | 特效 |
|------|------|------|
| 小刀 | 10 | 轻微击退 |
| 菜刀 | 15 | 中等击退 |
| 大剑 | 25 | 屏幕震动 |
| 鞭子 | 12 | 弹飞 |
| 毒水 | 5/秒 (可叠加) | 变绿减速 |
| 炸弹 | 40 | 爆炸粒子 + 强震动 |

## 场地物品

- **食物** (面包/苹果/水/果汁) — 火柴人低血时自动寻找并吃掉补血，吃完消失
- **家具** (椅子/沙发/床) — 火柴人休息后获得移速加成
- **桌子** — 障碍物，火柴人会绕行

## 快速开始

```bash
cd sourcecode
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

无需安装任何依赖，纯静态 HTML + Canvas + ES Modules。

## 技术栈

- **渲染**: Canvas 2D (火柴人、粒子特效、背景) + DOM (工具栏、UI)
- **语言**: 纯 Vanilla JavaScript (ES Modules)
- **部署**: Vercel (静态站点)
- **响应式**: 支持桌面 + 移动端触控
